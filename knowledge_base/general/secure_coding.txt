# Secure Coding Standard & OWASP Top 10 Guidelines

## 1. Injection Flaws (A03:2021)
- Never mix untrusted data with code or commands.
- Use parameterized APIs, object relational mappers (ORMs), and contextual output encoding.
- Validate all incoming parameters against strict schemas (whitelists) specifying type, length, format, and range.

## 2. Broken Access Control (A01:2021)
- Deny access by default. Enforce least-privilege principles on every protected endpoint and data model.
- Validate record ownership on every update/delete operation (prevent Insecure Direct Object References - IDOR).

## 3. Cryptographic Failures (A02:2021)
- Encrypt data at rest using AES-256-GCM.
- Enforce TLS 1.3 for data in transit with HTTP Strict Transport Security (HSTS).
- Use modern key derivation functions: Argon2id, PBKDF2 with >= 600,000 iterations, or scrypt.

## 4. Security Logging and Monitoring (A09:2021)
- Log security-relevant events (authentication failures, access denials, rate-limit triggers) with accurate timestamps.
- Sanitize logs to ensure PII, tokens, and credentials are never recorded.
